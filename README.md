# mymath

![Python](https://img.shields.io/badge/python-3.7%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![No dependencies](https://img.shields.io/badge/dependencies-none-brightgreen)

Учебная математическая библиотека на чистом Python без внешних зависимостей. Реализует базовые математические операции, тригонометрию, линейную алгебру, численное дифференцирование/интегрирование и статистику — **с нуля**, без использования `math`, `numpy` и других библиотек.

## ✨ Особенности

- 🚫 **Ноль зависимостей** — только стандартный Python
- 🔬 **Собственные реализации** алгоритмов: метод Ньютона, ряды Тейлора, алгоритм Евклида
- 📐 **Векторы и матрицы** с перегрузкой операторов
- 📊 **Численные методы** — производные, интегралы, градиент
- 🧪 **Проверки на ошибки** во всех критичных функциях
- 📖 **Понятный код** — идеально для обучения

## 🚀 Быстрый старт

```python
import mymath as mm

# Базовые операции
print(mm.sqrt(2))         # 1.414213562373095
print(mm.factorial(5))    # 120
print(mm.is_prime(97))    # True
print(mm.gcd(48, 18))     # 6

# Тригонометрия
print(mm.sin(mm.PI / 6))  # 0.5
print(mm.cos(0))          # 1.0

# Векторы и матрицы
v1 = mm.Vector([1, 2, 3])
v2 = mm.Vector([4, 5, 6])
print(v1.dot(v2))         # 32
print(v1.cross(v2))       # Vector([-3, 6, -3])

A = mm.Matrix([[1, 2], [3, 4]])
print(A.det())            # -2

# Производные и интегралы
f = lambda x: x**3
print(mm.derivative(f, 2))                # 12.0
print(mm.integrate(lambda x: x**2, 0, 1)) # 0.333...

# Статистика
data = [1, 2, 3, 4, 5]
print(mm.mean(data))      # 3.0
print(mm.std(data))       # 1.581...
```

## 📚 API

### `mymath.basic` — базовые операции

| Функция | Описание |
|---|---|
| `abs_val(x)` | Модуль числа |
| `power(base, exp)` | Возведение в степень |
| `sqrt(x)` | Квадратный корень (метод Ньютона) |
| `exp(x)` | Экспонента (ряд Тейлора) |
| `ln(x)` | Натуральный логарифм |
| `log(x, base)` | Логарифм по основанию |
| `factorial(n)` | Факториал |
| `gcd(a, b)` | НОД (алгоритм Евклида) |
| `lcm(a, b)` | НОК |
| `is_prime(n)` | Проверка простоты |

**Константы:** `PI`, `E`

### `mymath.trigonometry` — тригонометрия

| Функция | Описание |
|---|---|
| `sin(x)`, `cos(x)`, `tan(x)` | Основные функции |
| `asin(x)`, `acos(x)`, `atan(x)` | Обратные функции |
| `degrees_to_radians(deg)` | Градусы → радианы |
| `radians_to_degrees(rad)` | Радианы → градусы |

### `mymath.linear_algebra` — линейная алгебра

**`Vector`**
- `dot(other)` — скалярное произведение
- `cross(other)` — векторное (для 3D)
- `norm()` — длина
- Поддержка `+`, `-`, `*` (скаляр)

**`Matrix`**
- `transpose()` — транспонирование
- `det()` — определитель
- `A @ B` — умножение матриц

### `mymath.calculus` — матанализ

| Функция | Описание |
|---|---|
| `derivative(f, x)` | Первая производная (центральная разность) |
| `second_derivative(f, x)` | Вторая производная |
| `integrate(f, a, b, n)` | Интеграл (метод Симпсона) |
| `gradient(f, point)` | Градиент функции многих переменных |

### `mymath.statistics` — статистика

| Функция | Описание |
|---|---|
| `mean(data)` | Среднее |
| `median(data)` | Медиана |
| `variance(data, sample)` | Дисперсия |
| `std(data, sample)` | Стандартное отклонение |
| `covariance(x, y)` | Ковариация |
| `correlation(x, y)` | Корреляция Пирсона |

## 🧪 Тестирование

Запуск встроенных проверок:

```bash
python -m mymath
```

```python

assert abs(mm.sqrt(16) - 4.0) < 1e-9
assert mm.factorial(0) == 1
assert mm.is_prime(2) is True
assert abs(mm.sin(mm.PI / 2) - 1.0) < 1e-9

```
